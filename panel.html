✨ AI Summary

ChatGPT website needs no API key (opens a new tab). Choose an API provider to see generated text here. Add unlimited providers in Settings.

⚙️ Settings

API keys are saved only in local extension storage, not synced. Chrome asks for access to each API host when you run a request. Never enter your ChatGPT account password here.

For CyonaraAI, use its real OpenAI-compatible API URL, or choose Website handoff to copy the prompt and open your chatbot. ChatGPT web can also attempt to send directly.
